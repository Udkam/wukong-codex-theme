# Wukong Codex Theme

为 Windows Codex / ChatGPT 桌面客户端带来悟空背景与玻璃材质，支持深色和浅色主题。内置 10 张战斗图与 3 张风景图，可用快捷键切换。

## 开始使用

需要 Windows 和已安装的官方桌面客户端，无需另装 Node.js、Python 或 npm。

1. 下载上方 Windows 运行包，完整解压到固定文件夹。
2. 完全退出 Codex / ChatGPT，包括系统托盘中的后台实例。
3. 双击解压目录中的 **start.cmd**。

保留整个解压目录；日常使用主题时也从 start.cmd 启动。背景切换等快捷键见 [使用说明](docs/QUICK_START.txt)。

恢复原生界面：完全退出应用，再从官方入口启动。
