# Wukong Codex Theme v0.17.0

## 下载与使用

下载 **Wukong-Codex-Theme-0.17.0-Windows.zip**，不要选择 Source code。完整解压，首次启动前完全退出 ChatGPT/Codex（含托盘），双击 start.cmd。保留 start.cmd、使用说明.txt 和 app 的完整目录结构。

需要 Windows 与已安装的官方桌面客户端，无需另装 Node.js、Python 或 npm。SHA256SUMS.txt 提供下载校验。
