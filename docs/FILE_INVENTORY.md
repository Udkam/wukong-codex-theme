# 文件结构

## 用户下载包

| 项目 | 用途 |
| --- | --- |
| start.cmd | 唯一启动入口 |
| 使用说明.txt | 中文启动步骤、快捷键、常见问题 |
| app/ | 运行脚本、主题资源、清单、许可证；请勿拆分 |

没有安装、停止、删除或背景管理等额外 .cmd。运行所需 Node 由已安装的官方客户端提供。

## 远程源码

| 目录 | 用途 |
| --- | --- |
| runtime/ | 注入、生命周期、还原及 CSS |
| scripts/ | 启动、打包、资源构建和诊断工具 |
| shared/ | 主题模型与资源清单生成 |
| themes/ | 活动背景、玻璃资产和原生主题定义 |
| studio/ | 主题开发预览，不进入运行包 |
| tests/ | 回归与原生合同测试，不进入运行包 |
| docs/ | 快速开始、设计、验证与开发说明 |
| artifacts/test-runs/ | 现役测试依赖的少量历史证据，不进入运行包 |

## 本地保留

本轮从当前分支取消跟踪 255 个宠物和弃用主题材料文件，共约 87.48 MiB。包括宠物包、制作过程、宠物脚本/测试、旧截图、被否决设计、旧素材副本及过时阶段文档。文件均保留原路径，前后 SHA-256 一致，并加入忽略规则。提交不重写历史，所以旧提交仍能找到这些内容。

当前主题测试及其直接依赖仍保留。资源清单驱动下载包，不将本地存档或账户数据混入包中。
