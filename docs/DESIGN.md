# 大圣归来 · 潇湘双境：当前设计

更新：2026-09-21。当前注入版本为 v98-regional-refresh。本文件只描述仍有效的实现和边界，不保留已弃用设计方案。

## 原生界面边界

主题只替换背景材质。客户端组件的圆角、corner-shape、裁切、尺寸、间距、布局、命中区、焦点与禁用态全部由原生决定。透明定位容器保持透明，不能因带有 menu、dialog 或 tooltip role 就给它加底板。

输入框使用 ComposerLayout 的原生材质变量：对话页 ROOT 绘制，ChatGPT 首页 BODY 绘制。不得同时绘制两层。左侧历史预览由内部圆角面板绘制，外层 tooltip 只负责定位。环境信息使用 FloatingSurface island；PIP obstacle 是空的兄弟节点。

正文、执行记录、状态、模型、Ultra、权限、发送/取消、链接、增删差异、代码语法、选中和禁用颜色均保留原生。不添加 Ultra 白底或背衬。首页题字与悟空字标是主题自有内容，其原有绘制与开关保留。

## 材质与浅色适配

深色面板采用中性灰玻璃，当前底色 rgba(107,110,106,.94)，用较弱高光改善原生深蓝 Ultra 的背景对比，同时保留原生浅色文字。菜单、对话框、历史预览、输入框、环境信息与设置卡片共享材质变量；这是一项待用户视觉复核的折中，不代表所有原生字色都达到足够对比度。

设置侧栏与对话常驻侧栏共享按背景亮度调整的衬底及 blur(8px)：深色 24%–78%，浅色 10%–37.5%。只在背景提交时采样，原生形状、布局和裁切不变。设置页直接 sticky 控件外层透明并移除黑色渐变尾部，不改变内层输入或标签。

环境信息卡及 sticky 标题、顶部伪元素使用同一实色底，保留边缘阴影和原生几何。这里明确降低透明感，以保持滚动遮挡：透明标题的嵌套 backdrop-filter 会重复合成颜色，并从顶部原生 8px 区域漏出文字。普通行不增加滤镜。减少透明度或高对比模式关闭其余面板的模糊，并恢复原生不透明底色。

浅色模式按用户最新要求，在背景图片上均匀覆盖一层 14% 白色薄遮罩。图片资产和滤镜保持不变，不分阅读列，不按区域修改文字颜色；玻璃仍只在原生已有面板内绘制。此前材质与衬底候选均被用户否决，当前薄遮罩也仍需视觉复核；不能以计算样式一致或自动测试通过代替视觉通过。

设置中的原生主题预览、代码对比、颜色样本、开关及语义配色不套用面板材质。forced-colors 关闭主题图片和玻璃，reduced-motion 关闭主题过渡。

## 背景与资源约束

活动清单为 themes/active.json，当前 10 张战斗图与 3 张风景图。slot 是资产身份，order 是组内顺序。新任务默认 battle，项目和对话默认 scenery；普通流式文本增长和同模式页面变化不推进图片。

- Ctrl+Alt+F / B：当前组下一张 / 上一张。
- Ctrl+Alt+C：临时切换组，页面变化后恢复自动规则。
- Ctrl+Alt+K：锁定 / 解锁已显示的组和图片。
- Ctrl+Alt+T：显示 / 隐藏首页题字与字标。

最多两个背景层、一个可取消解码请求；解码成功后原位叠化，失败保留可见画面。隐藏页面延迟工作，回到前台合并恢复；不新增轮询、整页文字扫描或装饰图标扫描。
