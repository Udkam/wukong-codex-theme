# 当前设计：原生容器上的背景与玻璃

更新：2026-09-27，运行时 v104-native-surface-adaptation。

## 设计原则

以安装客户端原生组件划分绘制范围，直接替换各表面的材质。尺寸、位置、留白、边界和圆角全部继承原生。完整映射见 native-surface-adaptation.md。

图标轨道使用较实的背景，保障图标对比；对话、设置与 Customize 宽侧栏采用适度半透明磨砂。目录页面保留壁纸纹理，增加阅读衬底，避免浅色黑字直接落在暗壁纸上。标题填充原生 sticky 伪元素，随原生滚动范围裁切。

输入框、菜单和设置卡片使用玻璃；环境信息与代码标题采用不透明底以遮住滚动文字。悬浮提示保留原生反色配对。正文、状态、模型、权限、语法和增删色沿用原生；聊天列表局部文字变量与阅读衬底配套。首页悟空字标及题字为自有装饰。

## 连续性与性能

背景最多两层，解码完成再提交。设置更换 PageSurface 时复用相同节点与已解码图像，在绘制前重新挂载；不以重新解码修复容器替换。首次创建前设置页面状态，避免遮罩从默认 opacity 渐变。

普通流式文字与内联 Markdown 不刷新主题区域；组件挂载、路由、弹层和几何变化仍触发有界刷新。背景采样缓存依赖已提交图片及真实裁切，不读取或重写聊天正文。

常驻 host 每次协调读取运行时内容指纹，探针和注入来自同一模块，防止更新后修复回旧版本。源码更新后首次需更新旧 host；已更新的 host 随事件读取新模块，无新增轮询。

## 回退与范围

减少透明度关闭玻璃滤镜并使用不透明表面；强制色彩隐藏主题图片；减少动态关闭主题过渡。无可用原生 PageSurface 时保留视口兼容路径。

Electron 主进程系统菜单不属于 renderer CSS。适配承诺限于已审计版本和验证矩阵，未来组件重命名仍需更新映射。主题不修改官方安装包、账号或自动更新策略。用户验收与发布状态见 VALIDATION.md。
