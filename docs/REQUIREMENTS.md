# 新 UI 适配验收要求

目标客户端：Windows Codex 26.924.2738.0。

1. 按原生代码划分壁纸、图标轨道、宽侧栏、主内容、目录标题、输入框、卡片与浮层；不维护第二套宽高坐标。
2. 对话侧栏有适度背景，深浅模式下文字清楚；原生圆角、顶部留白和底边保持一致。
3. 设置往返保留背景节点和已解码图片，不重复加载或全量重注入；普通流式正文不触发主题扫描。
4. 图标提示保持原生前景背景配对；Library、Images、Plugins、Skills 的标题和正文均有正确阅读表面。
5. 保留原生字体、语义状态、输入交互、命中区域、选中与禁用行为；主题不重写正文。
6. 深浅模式、正常/窄窗口、滚动、页面切换、减少透明度、强制色彩与恢复原生均需验证。夹具通过与用户实机验收分开记录。
7. 完成适配后删除失效的旧方案测试和文案；仍有效的回归保护迁移。旧方案从 Git 历史恢复，不保留互相冲突的现行描述。
8. 实现修改必须注入本机供用户验收。未实际复现的问题不得标注已修复，也不得无证据归因原生 UI。
9. 运行包只包含活动主题与必要运行文件；不含本机诊断、聊天、宠物或退役材料。正式发布须有独立包验证及用户验收。
