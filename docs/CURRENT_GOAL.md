# 当前目标与发行状态

更新于 2026-11-13。**[v0.18.11](https://github.com/Udkam/wukong-codex-theme/releases/tag/v0.18.11) 已发布为 GitHub 最新正式版**。运行时为 v125-native-surfaces-and-reduced-motion，适配 Windows Codex 26.1106.6628.0（包内 26.1106.51428）。

新版修正语音专注模式底部、活动侧栏及导航悬停底色。启用减少动态效果时，壁纸在解码完成后直接切换。深浅色对照及范围见 [预览说明](previews/README.md) 和 [发行说明](RELEASE_0.18.11.md)。

此前标签页开合卡顿在恢复原生外观时也有复现。标签页开合沿用客户端动画，本版的减动效调整适用于壁纸切换。

[Windows 运行包](https://github.com/Udkam/wukong-codex-theme/releases/download/v0.18.11/Wukong-Codex-Theme-0.18.11-Windows.zip) 和 [SHA256SUMS.txt](https://github.com/Udkam/wukong-codex-theme/releases/download/v0.18.11/SHA256SUMS.txt) 均已重新下载核验。独立源码 197 项检查和 Studio E2E 通过，解压包在本机前台恢复原生及重新应用均通过。详见 [验证记录](VALIDATION.md) 和 [清理记录](CLEANUP.md)。

上一版的侧栏选中态、首页首帧和标签页变更见 [v0.18.10 发行说明](RELEASE_0.18.10.md)。
