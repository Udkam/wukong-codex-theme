# 当前目标与发行状态

更新于 2026-11-23。本轮发行版本为 **v0.18.14**，运行时 **v132-settings-native-hover**，适配 Windows Codex 26.1117.4957.0（包内 26.1117.41037）。用户已授权发布，当前进入发行验证与打包流程。

本轮包含侧栏实际壁纸取色、设置整行淡悬停、公共资料页与输入框修复，以及新版工作区、浏览器、查找条和内置插件推荐的材质适配，详见 [发行说明](RELEASE_0.18.14.md)。

设置「自定义规则」和导入历史恢复原生整行悬停，底色随深浅主题使用更淡的蓝灰色。侧栏使用用户已确认的实际壁纸取色与通透分层材质。

用户已确认资料页主体显示壁纸，并确认保留执行文字发光、仅关闭输入框背景模糊时，移动遮盖消失。正式规则仅停用普通对话输入框的背景模糊，保留底色、高光、阴影和原生执行动画；首页和其他玻璃浮层不变，首页字标保持原样。最终回归及实机范围见 [验证记录](VALIDATION.md)。

侧栏颜色随实际图片、裁切及窗口尺寸变化更新，浅色模式保留浅底并轻微染色；亮背景自动提高阅读衬底。沿用同一份 24×64 采样及缓存，不增加图片层、模糊层或逐行扫描。Activity、设置和目录材质保持独立，完整回归与实机结果见 [验证记录](VALIDATION.md)。

设置行的深色悬停底为 rgba(183,205,224,.055)，浅色为 rgba(76,107,132,.035)。鼠标交互沿用整行底色，键盘焦点沿用原生轮廓，图标使用原生颜色。深浅预览来源见 [预览说明](previews/README.md)，本次检查与注入结果见 [验证记录](VALIDATION.md)。

发行源码检查、运行包核验、实际注入与上传回读按执行结果记入 [验证记录](VALIDATION.md)。

此前标签页开合卡顿在恢复原生外观时也有复现。标签页开合沿用客户端动画。
