# Wukong Codex Theme v0.16.0

## 下载与使用

下载 **Wukong-Codex-Theme-0.16.0-Windows.zip**，不要选择 Source code。

1. 完整解压到固定文件夹。
2. 首次启动前完全退出 ChatGPT/Codex，包括系统托盘实例。
3. 双击 start.cmd。

需要 Windows 与已安装的官方桌面客户端；无需另装 Node.js、Python 或 npm，无需管理员权限。
解压后只有 start.cmd、使用说明.txt 和 app 三项，请保持它们在一起。

## 本版内容

- 深浅色玻璃材质，保留原生布局、文字与交互。
- 10 张战斗图、3 张风景图；对话默认雪山。
- 修复设置切换主题返回时背景重新加载。
- 简化下载包与中文使用说明，移除宠物和旧制作材料。

Ctrl+Alt+F/B 切换背景，Ctrl+Alt+C 切换背景组，Ctrl+Alt+K 锁定背景，Ctrl+Alt+T 切换新对话题字。

## 兼容与恢复

已在 Windows 官方桌面客户端 26.915.4065.0 验证当前注入效果；后续客户端若改变接口，可能需要适配。
主题不修改官方安装文件或自动更新策略。恢复原生：完全退出后，从官方入口启动 ChatGPT.exe。
若提示已有普通实例运行，请从托盘退出后重试。启动出错时保留错误窗口，到 Issues 反馈。
