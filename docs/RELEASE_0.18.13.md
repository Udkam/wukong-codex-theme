# v0.18.13 输入框状态材质

适配 Windows Codex 26.1111.2228.0，主题运行时为 v127。

文件变更徽标、排队消息和目标条出现时立即使用主题玻璃材质。浮动输入框中的透明条目沿用外层背景。文件增删数字、原生按钮、圆角和显隐动画保留。

深浅色预览使用当前客户端的原生组件和 CSS，文案为测试示例。[组件预览](previews/README.md) · [验证记录](VALIDATION.md)

解压 Windows 运行包后，完全退出桌面客户端，再双击 `start.cmd`。[使用说明](QUICK_START.txt)
