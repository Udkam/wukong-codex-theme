# v0.18.1：浮动输入框绘制范围修正

2026-10-06，运行时 v109-floating-paint-owner。

对照 Windows Codex 26.930.4958.0 的 FloatingSurface 与 QuickChat 原生组件：圆角类被定位外框和实际背景层复用，旧玻璃选择器同时绘制两层，产生多余厚边。

本版仅替换原生带背景材质的 FloatingSurface，定位外框保持透明。保留原生尺寸、位置、圆角和收起／展开交互；其他浮动面板的玻璃材质，以及背景队列、快捷键、自定义主题等既有功能继续保留。

## 验证与预览

- 深浅色各检查收起与点击展开两种状态；每种状态同步比较 78 个非 SVG 节点，所测几何和字体无差异。
- 更新 README 和两张真实客户端浮动输入框局部预览，不含聊天正文或标题。基础适配预览注明原有日期与版本。
- 从精确发行索引导出独立源码，运行回归与 Studio 检查；下载包解压后逐文件核验 SHA-256，并使用解压包实际恢复原生及重新注入。详细执行结果见 [验证记录](VALIDATION.md)。

本轮未执行完整冷启动、完整卸载或新的流式重载样本采集，不将这些范围列为已验证。未来原生语义接口变化仍可能需要维护映射。
