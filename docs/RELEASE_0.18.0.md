# Wukong Codex Theme v0.18.0

2026-10-04。原生 UI 适配重构，运行时 v108-native-surface-adapter；对照 Windows Codex 26.930.3930.0。

## 本版内容

- 将原生容器识别、可见性和绘制归属集中到 native-ui-contract.mjs，优先使用语义标记；保留原生布局、圆角、文字排版和交互，减少固定尺寸及工具类组合依赖。
- 保留背景队列、场景自动切换、锁定、快捷键、首页题字、深浅玻璃、设置往返复用与还原功能。普通对话与 dots 使用风景队列，新聊天使用战斗队列。
- 深色阅读区提供更稳定的文字、次要说明和链接颜色；主题 JSON 新增可选 materials.dark/light 材质配置，旧 schemaVersion 3 主题继续兼容。
- 添加面板的分组标题与滚动内容统一材质，改善说明文字对比度，保留选中、禁用、键盘和滚动操作。
- 清除 dots 输入控件后方的独立装饰渐变，避免底部黑带；保留原生输入控件。
- 补齐浏览器智能体权限表的深浅色材质，固定列采用不透明底色；保留圆角、横向平滑翻页和权限下拉。
- host 同时计算主模块和原生适配模块的指纹，单独更新映射也能重新应用到客户端。
- 清理失效注入方案、旧纹理、历史截图专测和重复文档，迁移有效回归保护；Git 历史、标签与既有发行版保留。

## 检查与边界

新客户端的共用原生样式与前一审计版本一致，全部现役语义接口存在。深浅色实机检查、独立源码回归、Studio 检查及下载包解压哈希验证的实际范围见 [验证记录](https://github.com/Udkam/wukong-codex-theme/blob/v0.18.0/docs/VALIDATION.md)。README 与六张实机预览已同步。

本轮未主动重启官方客户端，未额外执行完整冷启动；没有重新采集流式文字重载样本，不能将其写成已修复或原生 UI bug。当前映射可以减少布局变化带来的维护，但原生语义接口彻底改变时仍需更新。

## 下载与启动

下载 Wukong-Codex-Theme-0.18.0-Windows.zip，完整解压，完全退出官方客户端（含托盘），双击 start.cmd。目录包含 start.cmd、使用说明.txt 与 app，保持完整结构。SHA256SUMS.txt 提供校验。

本版正式运行包已包含原生表面适配模块及当前主题资源；GitHub 自动生成的 Source code 为开发源码。
