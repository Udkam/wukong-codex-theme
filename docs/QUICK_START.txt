悟空主题 · 开始使用

1. 将压缩包完整解压到一个固定文件夹，不要在压缩包内直接运行。
2. 首次启动前，完全退出 ChatGPT/Codex，包括系统托盘中的后台实例。
3. 双击 start.cmd，等待应用打开并加载主题。

需要 Windows 和已安装的官方 ChatGPT/Codex 桌面客户端。
无需另装 Node.js、Python 或 npm，无需管理员权限。
app 文件夹是必要运行文件，请与 start.cmd 放在一起，不要单独移动或删除。

日常使用
每次要使用主题时双击 start.cmd，可为它创建桌面快捷方式。
从官方 ChatGPT.exe 启动仍是原生界面。
想恢复原生界面：完全退出应用，再从官方入口启动。
应用正常自动更新；主题入口会在下次启动时重新查找已安装版本。

切换背景
Ctrl+Alt+F：下一张        Ctrl+Alt+B：上一张
Ctrl+Alt+C：切换战斗/风景组
Ctrl+Alt+K：锁定/解锁背景
Ctrl+Alt+T：显示/隐藏新对话题字
新对话使用战斗组；对话和项目页使用风景组，默认雪山。

遇到问题
提示应用已运行或没有主题：从托盘完全退出应用，再双击 start.cmd。
提示找不到客户端：先安装并正常打开一次官方桌面客户端。
启动窗口显示错误：保留错误内容，到仓库 Issues 反馈。
请勿仅复制 start.cmd；请重新解压完整文件夹。

卸载主题
完全退出主题启动的应用后，删除解压文件夹即可移除文件。
项目不会修改官方安装文件或接管官方启动入口。

项目与问题反馈：https://github.com/Udkam/wukong-codex-theme
