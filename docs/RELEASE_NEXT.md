# v0.18.16 发行完成

2026-11-24，运行时为 **v134-status-rail-compositing**，原生来源为 Windows Codex 26.1117.4957.0（包内 26.1117.41037）。用户已授权本轮修正与发布。

用户在目标条与排队消息中发现类似的间歇竖线，本轮沿用项目条的处理方式。独立状态条停用自身背景采样。浮动输入框内的透明状态条使用外层表面材质，带状态条时停用该外层的背景采样。底色、高光、原生边框、分隔线、圆角和控件仍按各自结构绘制。

右侧标签页按实际外层标题载体绘制原生底色，清理内层重复绘制，并按原生 me-1 间距对齐内容面板的起端和末端。空的独立边界装饰线沿相同间距平移。末端窄条和装饰线调整限定活动工作区中的可见分栏标题，左右书写方向分别对应逻辑末端。原生标签、按钮、内容与拖拽区域几何保持，首页字标沿用既有主题设置。

间歇竖线尚未稳定复现，真实材质计算样式、前台读回和用户确认分别记录。深浅色组件预览展示实际材质归属与布局。[组件预览](previews/README.md) · [验证记录](VALIDATION.md)

修正后的装饰线已在前台读回与内容 aside 起点一致，用户已实机确认右侧标签页现在对齐，最终样式和读回状态见 [验证记录](VALIDATION.md)。

同类检查发现，最小化浮动聊天的工作提示由独立 FloatingSurface notice 承载，拥有另一处背景采样。本轮按真实工作状态识别该表面并停用采样，其他独立提示和菜单沿用各自滤镜。审查范围见 [验证记录](VALIDATION.md)。

本轮改动已进入 [v0.18.16 正式发行](RELEASE_0.18.16.md)。最终独立源码 219/219 检查与 Studio E2E、38 文件包核验、同包恢复原生及前台重新应用、GitHub Latest 与两个资产回下载哈希校验全部通过。临时材料已清理，详见 [验证记录](VALIDATION.md) 和 [清理记录](CLEANUP.md)。
