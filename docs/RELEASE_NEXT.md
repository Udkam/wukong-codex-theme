# 下一版（开发中）

2026-11-23，运行时 **v131-sidebar-scene-palette**。适配 Windows Codex 26.1117.4957.0（包内 26.1117.41037）。

- 侧栏直接跟随实际壁纸取色，复用现有裁切采样与缓存；更通透的深色底、浅色轻染及亮背景阅读补偿随场景更新。普通侧栏和 peek 仅绘制一层材质，保留原生尺寸、文字、选中态与退出动画，Activity／设置／目录不受影响。
- 覆盖公共资料页真正的背景壳，并为滚动后的独立标题底板应用主题材质；顶部、滚动及回顶部保留原生布局和遮挡。资料设置页与公共资料页分别验证。
- 修正执行状态文字扫光干扰输入框：普通对话输入框采用无背景模糊的半透明材质，底色、高光、圆角及阴影保留；首页、独立浮层和执行文字动画不变。
- 重新设计「自定义规则」与导入历史的交互反馈：使用向上与两侧淡出的底部晕染，末端箭头保留淡金强调；不增加整行实色、描边、阴影或圆角。鼠标移开后恢复透明，展开不持续高亮，原生分隔线、键盘轮廓及布局保持。
- 按新版工作区的真实背景底板、替代外壳伪元素和顶部渐变清除残留实色，补齐查看器区域的渐变绘制归属。
- 为设置窗口整体及导航应用主题材质，资料设置页正文壳保持透明；默认平铺设置行沿用原生外观，显式盒装卡片继续使用玻璃材质。
- 适配侧栏 peek 包装的独立底色，并按当前浏览器标题栏的实际挂载范围绘制右侧标签区域，保留原生布局、控件及完整视图行为。
- 首页保持原有字标资源、文案、168px 尺寸与宿主透明度，首页清除原生外框灰色叠层，不添加额外遮罩。
- 为聊天查找条的实际内部底色节点补齐主题材质，外层定位、透明输入和查找控件沿用原生。
- 输入框仅替换原生有材质的变体，透明文档编辑画布及拖放反馈保留原生绘制，避免额外覆盖层。
- 保留 v128 的内置插件推荐适配：玻璃卡片、细描边、浅色图标底板与安装按钮配色随嵌入页加载和主题切换更新，恢复原生时清除。

首页建议面板及目标条等回归输入同步到当前原生组件，保留字体、尺寸、禁用状态、滚动和点击检查。深浅色图片来自当前原生结构与 CSS 的组件夹具，见 [预览说明](previews/README.md)；最终检查与实机验收范围见 [验证记录](VALIDATION.md)。
