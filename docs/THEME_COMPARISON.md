## 已同步的亮度逻辑

adaptShellToImage 已移除固定 14% 白色遮罩假设；两种主题均从已解码原图取样亮度，分别计算深色和浅色侧栏底色透明度。该算法是原图亮度启发式，不模拟每个渐变像素的最终合成。

设置往返保留背景模式，新增回归测试覆盖设置中切换主题后返回，断言背景层身份和绘制次数不变。实机诊断进一步发现，常驻注入器曾把刚挂载、尚未标记的输入框误判为主题失效，导致全量重注入。已移除持续健康检查中的该瞬时条件；启动验收仍检查输入框覆盖。已更新常驻进程，用户本轮实测确认无问题；记录中设置往返始终保留同一运行时及背景层。

风景队列改为 S08 雪山湖泊 → S05 夕阳山谷 → S01 峡谷楼阁。新配置的默认项为雪山；运行时仍保留用户手动选择和锁定，不强制每次进入对话重置背景。
