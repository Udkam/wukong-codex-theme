# 深浅色材质

更新：2026-09-27。几何均由原生容器决定。

| 表面 | 深色 | 浅色 |
| --- | --- | --- |
| 输入框与普通浮层 | 冷蓝灰 72%，12px 模糊 | 近白 60%，10px 模糊 |
| 图标轨道、应用顶栏 | 按图片裁切亮度取样，8px 模糊 | 同步浅色衬底，8px 模糊 |
| 宽侧栏 | 深灰 64%，12px 模糊 | 近白 60%，12px 模糊 |
| 目录内容面 | 深灰 86% 阅读底 | 近白 90% 阅读底 |
| 目录 sticky 标题 | 原生 ::before 填充宽侧栏材质 | 同左 |
| 用户气泡、tooltip | 原生配对 | 原生配对 |
| 对话壁纸 | 场景深色遮罩 | 按场景使用白色薄遮罩 |
| 首页壁纸 | 无遮罩 | 无遮罩 |
| 设置 | 保留进入前背景；卡片独立材质 | 同左 |
| 环境信息、代码块 | 不透明底遮挡滚动内容 | 同左，使用浅色底 |

默认场景与快捷键保持活动清单定义。模式切换不更改图片资源，设置往返不重新解码背景。减少透明度与 forced-colors 使用不透明/系统表面。测试范围见 VALIDATION.md。
