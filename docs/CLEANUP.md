## 历史恢复

使用 `git log --all -- <路径>` 查找历史，再用 `git show <提交>:<路径>` 查看；需要恢复时导出到独立目录。此次操作不重写历史、不删除既有标签和 GitHub Releases。源码删除随普通提交同步远程，最新正式版仍为 v0.17.3，本轮 v108 适配重构尚未发布。
