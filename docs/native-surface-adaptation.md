# 原生容器与主题材质

核对版本：Windows Codex 26.924.2738.0，2026-09-27。
依据安装目录 `app/resources/app.asar` 中的
`webview/assets/app-initial-5ba553174940.css` 与运行中的 DOM。

## 覆盖规则

| 原生容器 | 主题处理 | 几何来源 |
| --- | --- | --- |
| `PageSurface` | 内置惰性壁纸层，填满容器并继承圆角 | 原生 inset、响应式尺寸、四角半径 |
| 外壳留白 | 原生 surface-secondary 底色 | 原生外壳布局 |
| `group/sidebar-rail` 图标栏 | 原侧栏的叠层材质，原生图标颜色 | 原生导航轨道 |
| 默认侧栏外层 | 透明，避免重复叠色 | 原生侧栏宽高、裁切、分隔线 |
| `ConversationSidebar` | 单层半透明背景与 12px 模糊；深色 64%、浅色 60% | 原生侧栏轮廓，不新增遮罩 |
| 聊天列表内部 `Navigation` | 文字、次级文字及选中底色随深浅主题同步切换 | 原生字号、行高、间距 |
| 原生页面标题壳与内容面 | sticky 伪元素填充玻璃；目录/设置内容采用阅读衬底 | 原生标题滚动位置、圆角及内容面范围 |
| 输入框 | 使用原生 composer 材质变量填充玻璃 | 原生输入框轮廓与定位 |
| 浮层、菜单、设置卡片 | 在现有表面上填充玻璃 | 原生浮层定位与圆角 |

不再用侧栏宽度、工具栏高度拼接遮罩；不覆盖原生布局尺寸。
壁纸容器挂到原生页面绘制节点，侧栏拖宽不会产生第二套定位。
壁纸明暗采样使用真实图片裁切与聊天列表区域；窗口或侧栏尺寸改变时重新采样，普通内容刷新命中缓存。

## 适配边界

选择器使用语义属性和组件名片段，不绑定 CSS Modules 哈希。
原生尺寸、留白和圆角变化会自动继承；若后续版本删除或重命名容器，仍需更新映射，不能保证任意结构重写都自动适配。
未提供可见 PageSurface 的旧布局继续使用原有视口背景兼容路径。
壁纸替换与首页题字是主题自有装饰，不作为原生排版基准。

## 同页几何核对

运行 `node scripts/audit-native-geometry.mjs <CDP端口>`。
脚本同步读取主题开启/关闭时的原生节点，比较位置、宽高、圆角、定位、间距、字号与行高。
关闭样式期间隐藏主题图片，避免其进入文档流影响基准；在 finally 中恢复，不导航、不修改偏好。
报告仅包含结构与尺寸，不采集聊天文字。该检查只覆盖当前页面；其他页面仍需分别核对。
